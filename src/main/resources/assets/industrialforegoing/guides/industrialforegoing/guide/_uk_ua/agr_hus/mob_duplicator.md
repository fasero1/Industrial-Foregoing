# Дублікатор мобів

Машина, що використовується для спавну мобів. При забезпеченні енергією, [есенцією](./essence.md) та будь-якою сутністю в [інструменті ув'язнення мобів](../tools/mib.md) буде спавнити їх навколо себе. 

Буде підраховувати сутності поблизу та зупиниться, якщо їх забагато.
