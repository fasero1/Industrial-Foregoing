# Нескінченний тризуб

Нескінченний тризуб це інструмент, що дозволяє розкрити справжню силу тризуба. Підвищення рівня надасть вам доступ до різних рівнів <Color id="gold">вірності</Color>, <Color id="gold">течії</Color> та <Color id="gold">провідності</Color>. 

Провідність та шкода від удару будуть застосовані по площі.
