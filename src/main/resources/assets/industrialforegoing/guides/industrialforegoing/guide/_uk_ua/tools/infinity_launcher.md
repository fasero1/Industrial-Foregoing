# Нескінченна пускова установка

Нескінченна пускова установка це інструмент, що дозволяє захоплювати або звільняти сутності з захоплювача мобів на відстані. Обравши режим в інтерфейсі та стріляючи з пускової установки, ви зможете звільняти або захоплювати мобів, використовуючи захоплювач мобів у вашому інвентарі.
