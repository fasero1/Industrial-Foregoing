# Нескінченні інструменти

Нескінченні інструменти слідують простому принципу: чим більше енергії вони мають, тим кращі вони є. Підвищення рівня може надати інструменту спеціальні переваги. Наявність [біопалива](../biofuel.md) в них зробить їх більш ефективними, споживаючи паливо замість енергії при використанні. 

Ви можете <Color id="gold">присісти+правий клік</Color> для відкриття інтерфейсу інструмента.

Ви можете вимкнути <Color id="gold">зарядку</Color> інструмента, вимкнувши зарядку в інтерфейсі інструмента. 

Існує 7 рівнів: 
- Бідний
- Звичайний
- Незвичайний
- Рідкісний
- Епічний
- Легендарний
- Артефакт 

 Всі інструменти телепортуватимуть дропи до гравця.
