# Нескінченний рюкзак

Нескінченний рюкзак це інструмент, що дозволяє зберігати великі кількості предметів у портативний спосіб.

Він може утримувати 3 специфічні рідини: <Color id="gold">біопаливо</Color> для забезпечення роботи автоматичних операцій, <Color id="gold">есенцію</Color> з підібраного досвіду (коли увімкнено автопідбір) та <Color id="gold">рідке м'ясо</Color> для автоматичного годування.

Коли увімкнено <Color id="gold">режим магніта</Color>, близькі предмети будуть телепортовані до гравця, коли їх можна підібрати. 

Коли увімкнено <Color id="gold">режим автопідбору</Color>, предмети, що можуть потрапити в рюкзак, підібрані гравцем, автоматично потраплять в рюкзак. 

Кожен слот можна налаштувати на <Color id="gold">знищення</Color> надлишку або на <Color id="gold">поповнення</Color> неповних стопок у вашому інвентарі.
