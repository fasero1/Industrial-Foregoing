# Екстрактор рідин

Екстрактор рідин видобуватиме [латекс](./latex.md) з деревини, що розміщена перед машиною. Кілька екстракторів можна використовувати для видобутку з одної колоди одночасно. 

Машина почне споживати колоду, і після споживання видалить кору з неї та замінить на обтесану версію, після споживання якої вона зникне.
