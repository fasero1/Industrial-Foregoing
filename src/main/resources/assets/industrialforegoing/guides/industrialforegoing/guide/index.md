# Industrial Foregoing Guide

Welcome to the complete guide for Industrial Foregoing!

## Getting Started

Industrial Foregoing is a technology mod focused on automation and resource processing.

### Basic Setup

1. Start by collecting **Latex** from trees using the Tree Fluid Extractor
2. Process Latex into rubber using the **Latex Processing Unit**
3. Create **Plastic** from rubber to craft advanced machines

## Categories

- **Machines** - Core processing machines
- **Generators** - Power generation
- **Agriculture** - Farming automation
- **Storage** - Advanced storage solutions

## Quick Access

Press **G** while hovering over any Industrial Foregoing item to quickly jump to its guide page!
