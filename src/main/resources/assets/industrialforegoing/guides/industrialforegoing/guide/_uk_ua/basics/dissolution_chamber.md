# Фабрика крафту

Потужна машина, що використовується для крафту матеріалів з використанням до <Color id="gold">8</Color> предметів та/або <Color id="gold">1</Color> рідини. 

Всі рецепти безформні, що означає, що інгредієнти можуть бути розміщені в будь-якому слоті.
