# Latex Processing Unit

The **Latex Processing Unit** is the foundation machine of Industrial Foregoing, converting latex and water into tiny dry rubber.

## Recipe Requirements

- **100mb Latex** (collected from Tree Fluid Extractor)
- **500mb Water**
- **Power**: 20 RF/t

## Output

- **1 Tiny Dry Rubber** per operation

## How to Use

1. **Place the machine** in your base
2. **Connect power** - accepts RF, FE, and other energy types
3. **Input fluids:**
    - Latex via fluid pipes or tanks
    - Water via fluid pipes or tanks
4. **Output:** Tiny Dry Rubber appears in the output slot
5. **Automate** with item pipes for continuous operation

## Integration Tips

- **AE2**: Use Import/Export buses for automation
- **Pipez**: Connect fluid pipes for automatic input
- **Mekanism**: Energy and fluid compatibility
- **Storage**: Store rubber in AE2 storage systems

## Automation Setup

```
Tree Fluid Extractor → Fluid Tank → Latex Processing Unit → Storage
                                ↑
                            Water Source
```
