# Гідропонна грядка

Ця машина в поєднанні з енергією та <Color id="gold">водою</Color> (або <Color id="gold">лавою</Color> для пекельних культур) трохи прискорить ріст культур. 

Забезпечивши малою кількостю [етерного газу](../resource_production/ether_gas.md), культури ростимуть набагато швидше та будуть автоматично пересаджуватися.
