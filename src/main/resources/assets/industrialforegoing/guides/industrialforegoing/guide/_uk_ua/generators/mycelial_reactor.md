# Міцеліальний реактор

Використовуючи <Color id="gold">міцеліальну мережу</Color> (підпросторову область, що містить живу вегетативну масу грибка, званого міцелієм), цей реактор може виявляти інші <Color id="gold">міцеліальні генератори</Color> та генерувати величезні кількості FE. 

Для цього потрібно, щоб один екземпляр кожного генератора працював одночасно.
